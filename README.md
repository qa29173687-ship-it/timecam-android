# 時間相機 Android（TimeCam）

給中和安邦社宅報修現場使用的浮水印相機（Kotlin + CameraX）。

- 照片／影片切換，浮水印直接燒錄進照片與影片（預設「時間地址」：大時間、黃線、日期星期、地址；另有 5 種舊樣式可在「範本」切換）
- 縮放（雙指／0.5x·1x·2x·10x）、點擊對焦測光、曝光補償、閃光燈（自動/開/關）、手電筒、前後鏡頭、HDR／夜間（裝置支援時）
- 按下快門立即震動與白屏回饋，可選快門聲（設定可關；靜音／震動模式不出聲）；拍完可立刻再拍，浮水印在背景燒錄
- 設定可選「照片畫素」：依手機相機實際支援的尺寸（約 N MP／最高），預設約 12MP
- 儲存至 DCIM/時間相機，檔名如 `20261021_101402_A-1023.jpg`，會出現在系統相簿
- 可選「自動上傳 Google 雲端」：只把原檔傳到一個指定資料夾（預設「時間相機」），App 不會分類。可選拍完馬上或每天指定時間，並可限制只在 Wi‑Fi／充電時上傳

建置：`./gradlew assembleRelease`（簽章設定放在未納入版控的 `keystore/keystore.properties`）。

Google 雲端上傳需要在 Google Cloud 為套件名稱 `tw.timecam` 與釋出金鑰 SHA-1 建立 Android OAuth 用戶端，並啟用 Drive API。尚未設定時，App 會顯示「需要設定 Google 登入」，其餘功能仍可使用。
